# Occasionly Constitution

## Principles

1. Local-first architecture
2. Graceful degradation
3. Zero paid dependency lock-in
4. AI is enhancement, not dependency
5. Reminder logic must be recoverable
6. WhatsApp integration must remain API-independent
7. Event engine must support extensibility
8. Privacy-first design
9. Idempotent reminder processing
10. Minimal operational cost
